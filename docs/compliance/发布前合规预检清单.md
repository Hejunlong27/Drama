## 一、发布前三问（逐集必做，全「否」才可发布）

| # | 问题 | 为什么问 |
|---|---|---|
| Q1 | **方法是否出现？** | 是否呈现任何可被模仿的操作信息（步骤、工具、剂量、手法） |
| Q2 | **主体是否出现？** | 含**背景、屏幕画面、镜面倒影、监控屏**——不是只看主角 |
| Q3 | **身份是否歧义？** | 校服 / 学生装 / 童装风格会被读作未成年；涉事角色须**成人化着装** |

任一为「是」→ 走「**镜头外化**」整改后再发。

```powershell
python stages/production/scripts/compliance_precheck.py --workspace "D:/剧/新剧" `
    --ep ep01 --q1 no --q2 no --q3 no
# 退出码 2 = 不可发布
```

## 三、处置档位

| 内容形态 | 档位 | 平台动作 | 通知措辞特征 |
|---|---|---|---|
| 真实自杀/自伤、方法教学、美化宣扬、可模仿细节 | **删除档** | 移除视频，可能叠加违规记录 | 「视频已被移除」「违规记录」 |
| 描写真实暴力的血腥画面、真实事故惨状 | **删除档** | 移除 | 同上 |
| **虚构影视内容**中的自杀/自残情节（非血腥、无方法细节） | **降流档** | 保留但排除出 For You Feed + 年龄限制 18+ | 「在 For You Feed 等场景分发受限」「允许替换原视频」 |
| 成年人的性暗示、饮酒吸烟、不实信息、轻度不适画面 | **降流档** | 排除出 For You Feed（不判违规） | 同上 |

## 四、整剧级两条硬要求

### 4.1 AIGC 标注（平台硬要求）

AI 生成内容用于**真实还原人物或场景**时必须**明确标注**。做法：全剧统一在片头/片尾/文案位固定标注，**不要只在部分集标注**。

### 4.2 受限集数占比 ≤ 10%

```
受限占比 = 受限集数 / 总集数
上限     = ceil(0.1 × 总集数)
剩余余量 = 上限 − 已受限集数
```

超过警戒线会「**影响整体发布**」。

```powershell
python stages/production/scripts/compliance_precheck.py --workspace "D:/剧/新剧" `
    --all --aigc-label yes --restricted 3 --total 30
```

## 五、整改三硬标准 + 通用安全拍法

**整改方案缺一不可**

1. **主体不出现**（含背景、镜面反射、监控屏幕）
2. **方法不出现**（不得呈现任何可被模仿的操作信息）
3. **身份不歧义**（涉事角色成人化着装，切断校服/童装联想）

**通用安全拍法（建议固化为项目标准）**

> 死亡情节一律「**镜头外发生 → 事后发现 → 以调查与对白推进**」。

**行动顺序（不可颠倒）**：**先替换，后申诉**。申诉材料里的时间码必须与整改后实际处理一致，否则直接削弱可信度。

## 六、打码的边界（务必对用户明说）

- **打码 ≠ 合规**：遮挡块本身即「敏感内容标记」，仍可能被判降流。
- 打码**不能替代**：① AIGC 标注 ② 年龄提示。
- 打码要求：块 24–32px（<18px 会保留人形轮廓 = 失败）；保持**时长与帧数与原片完全一致**；`-c:a copy`。
