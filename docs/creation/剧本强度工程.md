# 剧本强度工程（S3 强化版）

> 日期：2026-10-16 ｜ 适用范围：`stages/creation/scripts/script_rewrite.py` 的 ④剧本改写环节
> 起因：用户实测**两个试验项目**（西语线）成片效果不佳，共同症状是**剧本过于简单、缺乏爽点引爆感**。
> 本文是**通用方法论**（不限题材）；具体题材的落地公式见 `stages/creation/references/genre-formulas/`。

## 一、问题诊断：为什么剧本会「简单、不爽」

剧本简单不是「内容少」，而是**结构性缺陷**。逐条列根因，每条都对应可操作的处置：

| # | 根本原因 | 症状（观众侧感受） | 处置 |
|---|---|---|---|
| 1 | **只写事件，不写落差** | 女主很惨却不觉得爽 ——「惨」没有对比坐标 | 每个爽点**成对出现**：先给可量化的「失」（钱/位/名/关系），再给可量化的「得」，得失都有数字或具体物件 |
| 2 | **压迫不透，反弹无力** | 打脸没回响 —— 观众心里没积压怒气 | **压到底**：前 3 集内 ≥3 个连续不利事件，其中 ≥1 个**当众发生**且有具体羞辱动作 |
| 3 | **对手无阶梯，一次性解决** | 反派早早被打倒，后面变成日常流水 | **四级阶梯**：L1 势利小人物 → L2 中层对手 → L3 实权者 → L4 隐藏大 boss；打倒一级**立刻暴露下一级** |
| 4 | **打脸没有见证者** | 爽感放大器缺席 —— 无人围观，羞耻感无从产生 | 每次打脸**必须有人看**；羞辱与反击**在同一场景回收**（同一批人先看她被踩、再看她打回去） |
| 5 | **情绪节奏是平的** | 连续同强度 → 两集就疲劳 | **压放呼吸**：每 3 集内至少 1 次「压」+ 1 次「放」；**禁止连续 3 集同向** |
| 6 | **反转前没让人先相信** | 反转不惊喜 —— 观众没来得及信，就被告知「不是这样」 | **先立信再打破**：反派的高光必须真实存在；底牌**分 3 次亮**，EP1 只露一角 |
| 7 | **台词没有攻击性** | 记不住任何一句 —— 没有可截屏、可传播的句子 | **金句三条件**：短（≤12 字）+ 具体（点出对方痛处的事实）+ 有物；每集 ≥1 句 |
| 8 | **前 3 集先铺垫** | 留存断崖出现在 EP1-3，后面再好也来不及 | **EP1 黄金 3 秒**：最高冲突前置；背景信息**拆碎塞进冲突里说**，禁交代式开场 |

> **两个试验项目的具体失误**（已写入公式的 `root_causes[].evidence`）：
> ① EP1 交代人物关系与背景，EP2 才起冲突；② EP1-3 用旁白讲委屈而不是让她在镜头里再受一次；
> ③ 第 3 集就明牌女主真实身份，导致后面所有反转失效；④ 后半段无对手，第 10 集前后弃剧；
> ⑤ 大量一对一私下交锋，无人围观；⑥ 连续 4 集「忍」+ 连续 3 集「爽」。

## 二、可落地的改写策略（五类）

### 2.1 悬念铺设：先立信，再打破

- **底牌三次亮**：EP1 露一角（观众知道她不是软柿子，但不知道是什么）→ 中段亮一半（能力/身份）→ 终局全亮（真相/底牌）。
- **明牌时机**：主角的**真实身份**最迟在**第二幕中期**亮出，此前只能给「反常细节」提示（做事的熟练度、别人对她的态度异常）。
- **反派立高光**：反派必须**真的赢过一次**（真的当众羞辱成功、真的夺走了东西），否则主角的胜利没有含金量。
- **信息差设计**：观众知道得比对手多（要看她怎么打回去）；关键节点让观众比主角少（制造揪心）。

### 2.2 冲突升级：对手必须一级一级变硬

- **阶梯不变**：L1 势利小人物（同事/亲戚/闺蜜）→ L2 中层对手（主管/继妹/合伙人）→ L3 实权者（家族长辈/企业高层/资本方）→ L4 隐藏大 boss（真凶/生父/前夫家族）。
- **升级两种方式**：① 换更强的对手；② 同一对手**动用更大的资源**（从私人恩怨 → 职场格局 → 资本与法律）。
- **每次循环必须「拿走一样 + 暴露一样」**：拿走可量化的所得（职位/合同/股份/道歉），暴露下一个更大的对手或隐情。缺任一，循环无效。

### 2.3 情绪节奏：压放呼吸

- **循环**：压 → 放 → 悬（3 集一个呼吸周期）。
- **压的类型**：被误解、被夺走可量化之物、被当众否定、盟友动摇、能力受挫。
- **放的类型**：小胜落点、被认可、对手吃瘪、得到关键信息、关系升温。
- **阶段例外**：触底段（P1）**全部为压**（释放感越晚越强）；终局段（P5）以「扬/燃」为主。
- **禁止**：连续 3 集同向。

### 2.4 高潮与反转设计：五拍打脸法

每一次打脸**必须五拍齐全**，缺一拍即判定「打脸未完成」：

| 拍 | 名称 | 内容 | 常见失误 |
|---|---|---|---|
| 1 | 挑衅 | 对方高姿态 + 一个具体羞辱动作 | 只写「她嘲讽她」，没有具体动作 |
| 2 | **压制** | 女主暂居下风，**让观众短暂相信她这次要输** | **最常被漏掉的一拍** —— 没有「以为她要输」就没有「她赢了」 |
| 3 | 反转 | 底牌出（证据/身份/实力/第三方见证），且底牌**前文埋过** | 临时掏出没埋过的底牌 = 金手指，爽感归零 |
| 4 | **见证** | 围观者反应特写：震惊、失语、倒戈、道歉 | 又一处高频遗漏 —— 爽感放大器 |
| 5 | 追加一击 | 金句 + 条件加码（断亲/撤资/公开证据），把对方钉死 | 打完就走，没有余韵 |

### 2.5 爽点密度与铺垫

- **密度**：打脸节拍**从阶段末集往前数**（阶段收束处必是高潮）：
  P1 每 3 集（触底段只在末集给一次最小反击）｜P2 不打脸（立誓与埋点）｜P3 每 2 集｜P4 每 3 集｜P5 **每集**。
- **铺垫的定位**：铺垫不是「前戏」，而是**在冲突里给信息**。每个铺垫必须服务于 3 集内的一个爽点；服务不到的铺垫删掉。
- **爽感三要素**（缺一即弱）：**落差**（先踩多深）+ **见证者**（有人在看）+ **金句**（一句话钉死）。
- **事业线**：每 5 集一个**能说出口的量化节点**（拿下客户/自立门户/签下大合同/拿回股份），且必须由**女主的决策**推动，不得靠他人赠送 —— 这是逆袭的**可信度来源**。

## 三、执行步骤（S3 完整流程）

```
① 源稿就位
   03-剧本/source-script.md（原语言）
   └─ 非目标语 → 先跑转译：script_translate.py plan/check（见 prompts/s0b-script-translate.md）

② 定路线（二选一）
   A 常规：③选题定位 → positioning.json
   B 题材公式：命中关键词（如「女主逆袭」）→ genre_formula.py apply → 跳过 ③选题
     python genre_formula.py --workspace <ws> match "女主逆袭"
     python genre_formula.py --workspace <ws> apply --genre female-comeback

③ 集数规划（结构层，脚本产出）
   python script_rewrite.py --workspace <ws> plan [--genre female-comeback]
   → 04 blueprint.json：每集 cold_open / core_conflict / reversal / hook
     +（公式模式）punch / punch_level / witness / stake / milestone / quote

④ 逐集正文（LLM 层）
   按 prompts/s3-script-rewrite.md 写正文 → script_rewrite.py build --ep N --emit → tools/cli.py check/parse/convert

⑤ 结构与格式自检
   script_rewrite.py lint --ep N      （FFS 结构 + 留存四件套 + 时长口径）

⑥ 公式 QC（公式模式下）
   genre_formula.py --workspace <ws> check --genre female-comeback
   （打脸节拍 / 等级下限 / 阶梯只升不降 / 见证者 / 金句 / 里程碑 / 前 3 集钩子 / 压放呼吸）
```

**前 3 集的爆款钩子公式**（公式模式自动写入 blueprint，不可改的骨架）：

| 集 | 开场（cold_open） | 集尾钩子（hook） |
|---|---|---|
| EP1 | **黄金 3 秒**：全剧最高冲突前置（当众被打脸瞬间 / 最惨时刻 / 身份反差） | 底牌露一角：观众知道「她不是软柿子」，但不解释是什么 |
| EP2 | 压力加码（第二件坏事）+ 明确对手是谁 | 立誓：说出要拿回什么、向谁拿 |
| EP3 | 第一次反击的起点 | 首次小打脸落点 + 暴露下一级对手 |

钩子类型 EP1-3 **互不相同**，且不得与前 2 集连续重复。

## 四、台词设计：可以更大胆

短剧的爽感有一半在台词上。**允许攻击性、允许冒犯、允许把话说绝**（只要不碰合规红线）。

**允许**：直接揭对方短处（当众点名事实）｜明确的条件与最后通牒（「今天之内搬走」）｜冷调反讽（少字、不留情面）｜亲属关系里的狠话（断亲、逐出、罢免）。

**禁止**（一律判定为无效台词）：

- 空话式威胁：「我一定会让你付出代价」「你们会后悔的」
- 解释型台词：把观众已经看到的事再说一遍
- 工具人台词：「我发现了一个秘密」却不说是什么

**金句规则**：反击句 ≤12 字 + 含一个具体事物（人名/物件/数字/关系）；放在五拍的第 5 拍；每集 ≥1 句可摘录句。

示例（女频逆袭公式 `quote_bank`）：冷调反讽「轮到你求我了」｜当众揭短「这份合同，你没签过字吧」｜最后通牒「三分钟，搬完」｜断绝关系「这门亲，我不认了」。

## 五、质量控制标准

| 检查项 | 阈值 | 校验方式 |
|---|---|---|
| 每集四件套 | `cold_open` + `core_conflict` + `reversal` + `hook` 缺一即返工 | `script_rewrite.py lint` |
| 反转有效性 | 必须**改变力量对比或信息格局**（仅情绪起伏不算） | lint 判定 + 人工复核 |
| **EP1 黄金 3 秒** | EP1 前 3 秒必须出现全剧最高冲突，禁铺垫开场 | 公式 check |
| 打脸节拍 | 按阶段（P1 每 3 / P3 每 2 / P4 每 3 / P5 每集，从末集倒数） | 公式 check |
| 打脸五拍 | 五拍齐全，**第 2 拍（压制）不得省略** | 人工复核（字段 `punch` 已标注） |
| 见证者 | 每次打脸 ≥1 个见证者 | 公式 check（`witness`） |
| 阶梯只升不降 | 打脸等级单调不减 | 公式 check |
| 压放呼吸 | 每 3 集至少 1 压 1 放；触底段例外（全压） | 公式 check |
| 金句 | 每集 ≥1 句可摘录反击句 | 公式 check（`quote`） |
| 事业线里程碑 | 每 5 集 1 个可量化节点（P3 起） | 公式 check |
| 前 3 集钩子 | 三集类型互不相同，且不与前 2 集连续重复 | 公式 check + lint |
| 语句密度 | 每句台词必须有功能（推进/引爆/揭示/悬念/关系），无功能不写 | 人工复核 |
| 时长口径 | 单集 70–95 秒（目标 70）、每集 5–12 镜、单镜 4–15 秒 | `tools/cli.py check`（E006） |
| 台词语速 | 按目标语种语速折算（中文 4.2 字/秒；见 `docs/creation/台词时长审计口径.md`） | `script_timing_check.py` |

## 六、题材公式机制（如何跳过选题）

**目的**：同一套题材反复生产时，不必每次重跑选题，直接用**固定公式**保证「爽点结构不缺件」。

- **真源**：`stages/creation/references/genre-formulas/<id>.json`（结构化）；同名 `.md` 由 `genre_formula.py doc --write` **生成**，勿手改。
- **路由**：`genre_formula.py match "<用户输入>"` 按关键词命中（取最长匹配）。
- **跳过选题**：`apply` 落 `<工作区>/03-剧本/genre-plan.json`（含 `skip_topic: true`）；此后 `script_rewrite.py plan` **自动走公式模式**，无需 `positioning.json`。
- **选题环节本身不动**：未命中的题材仍走 ①调研 → ②破拆 → ③选题 的常规路线。
- **扩展方式**：新增题材只需放一份同名 JSON，再跑 `doc --write` 生成文档 —— **无需改代码**。

已收录：`female-comeback`（女频逆袭 · 大女主事业线与绝地反击叙事）。

## 七、一页速查

```
爽感 = 落差 × 见证者 × 金句
落差：先踩多深 → 再翻多狠（每 3 集至少 1 压 1 放）
见证者：羞辱与反击在同一批人面前回收
金句：≤12 字 + 具体事物 + 放在第 5 拍

打脸五拍：挑衅 → 压制（★不可省）→ 反转（底牌必须埋过）→ 见证 → 追加一击
对手四级：小人物 → 中层 → 实权者 → 隐藏大 boss（打倒一级立刻暴露下一级）
循环铁律：每轮必须「拿走一样 + 暴露一样」
前 3 集：黄金 3 秒 → 立誓 → 首个小打脸（三集钩子类型互不相同）
```

**三条最容易犯的错**：① 省略第 2 拍压制 —— 爽感全失；② 没有见证者 —— 打脸无回响；③ EP1 先交代背景 —— 留存在这里就丢了。
