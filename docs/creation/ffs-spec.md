# FFS 剧本规范（本项目裁剪版）

> 基于 `overseas-ai-comic-script-master/references/storyboard-format.md` 裁剪改写。
> 差异：中文 / PLATFORM=TikTok / 时长口径 90–120 秒 / 去掉美式 localization 要求 / 新增可选 `DUR` 字段。

## HEADER（文件顶部，只写一次，顺序固定）

```
# TITLE: 平行世界的另一个我
# EP: 01/20
# PLATFORM: TikTok
# STYLE LOCK: <与项目库内完全一致的一整行英文常量>
# CHAR: LIN_YU: <锚点>; SU_WAN: <锚点>; ZHOU: <锚点>
# SCENE: APT: <描述>; LAB: <描述>; CORR: <描述>; CTRL: <描述>
```

- `STYLE LOCK` 必须**逐字复制** `bible/stylelock.md` 里的英文常量，一个标点都不能改（E011 会比对前 60 字符）。
- `CHAR` 只写本集出场角色。`SCENE` 只写本集用到的场景。
- 代号用大写英文 + 下划线。镜头块内**只许引用代号**，不许重写完整锚点。

## 镜头块

```
---
[SC-01]
SHOT: 大特写, 固定
LOCATION: APT
TIME: 夜
CHAR: LIN_YU
ACTION: 动作+表情+道具，必须包含一个已登记的代号或角色中文名
DIALOG: "对白" 或 无
VO: NARRATOR: 旁白 或 无
SFX: 音效描述 或 无
DUR: 8
```

### 字段规则

| 字段 | 必填 | 说明 |
|---|---|---|
| `SHOT` | ✅ | 景别(, 运镜)。景别取值：特写 / 大特写 / 中景 / 全景 / 俯拍 / 仰拍 / 第一人称视角。运镜：推 / 拉 / 摇 / 跟随 / 固定 / 旋转 |
| `LOCATION` | ✅ | 必须在 HEADER 的 SCENE 表登记过 |
| `TIME` | ✅ | 日 / 夜 / 黄昏 / 黎明 / 雨夜 |
| `CHAR` | ✅ | 必须在 HEADER 的 CHAR 表登记过；无人物写 `无` |
| `ACTION` | ✅ | 1–2 句。必须含角色名或场景代号（否则 E009）。**禁止抽象词**（气氛微妙 / 意味深长 / 情绪复杂 / 百感交集），一律改写为具体动作与表情 |
| `DIALOG` | ✅ | ≤2 句，单句 ≤20 字。无则写 `无` |
| `VO` | ✅ | 带说话者前缀 `NARRATOR:` 或 `角色名 (V.O.):`。无则写 `无` |
| `SFX` | ✅ | 无则写 `无` |
| `DUR` | ⭕ | **本项目扩展字段**，单镜预估秒数，4–15。缺省按 8 秒计 |

除 `DUR` 外**禁止新增字段**（`MOOD:` / `CAMERA:` / `EMOTION:` 一律触发 E004）。

## 时长口径（重要）

| 项 | 区间 |
|---|---|
| 单镜 | 4–15 秒 |
| 单集镜数 | 6–15 镜 |
| 单集总时长 | **90–120 秒** |

Seedance 的镜头切分算法（慢/中/快节奏 → 6–15 镜）就是按这个区间调的，不要越界。
排布建议：开场钩子 1–2 镜短促（4–6 秒），中段对话 8–10 秒，情绪高潮 10–15 秒，集尾钩子短收（5–8 秒）。

## 单集结构

```
强钩子开场   ：异常画面 / 高能对白 / 冲突切入（第一镜头就要抓住人）
设定交代     ：核心冲突、规则、身份、困境
主角行动     ：行动 + 对手施压 + 第一次反转
关系推进     ：甜 / 燃 / 升级 / 铺垫
冲突顶点     ：打脸 / 爆发 / 揭露
余波 + 集尾钩子：留一个让观众想看下一集的悬念
```

每 10–15 镜（即每 1–2 集）设一个情绪峰，防止平铺。

## 跨集连续性

- 每集结尾保留「上一集钩子的落点」+「本集新钩子」，闭环推进。
- 角色锚点、场景代号全剧恒定；关键道具造型全剧恒定。
- 新集复用上一集 HEADER，新增角色/场景时才追加到 CHAR/SCENE 表。
- **只准增量新增，不准重写 HEADER**——重写即触发锚点 hash 不一致（E002）。

## 中文适配要点

- ACTION 里写**角色中文名**（如「林宇推开实验室的门」），校验器同时接受代号与中文名。
- 对白要口语、短促，符合短剧节奏；情绪靠画面（ACTION）表达，对白只承担「推进信息」或「引爆情绪」。
- 反派对白要有智商：他的威胁是合理的，只是被主角破解。
