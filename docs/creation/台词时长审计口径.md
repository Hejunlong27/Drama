# 台词时长审计口径（4.2 字/秒）

- 日期：2026-10-16 ｜ 来源：Skill `script-timing-resegment`（口径逐字沿用，**不得私改**）
- 可执行：`python stages/production/scripts/script_timing_check.py --workspace <ws> --ep ep01`
- 挂载位置：**`3d-short-drama-studio` 环节 4 分镜的下游** —— 分镜稿产出后、进入 H3 提示词装配之前执行。

---

## 一、时间模型

| 项 | 口径 |
|---|---|
| **有效台词** | 镜内引号中**全部人声**（普通对白、`角色名画外音继续`、`角色名OS`、机械播报音）；**不含标点与说明文字** |
| **折算语速** | **4.2 字/秒**（短剧配音中速，含正常停顿） |
| **判定** | `> 上限` = **超载**；`< 目标下限` = **偏轻**（动作/空镜承载情绪的落点可接受，不必强补台词） |

## 二、单元容量换算表

| 单元时长 | 上限字数 | 目标区间 |
|---|---|---|
| 30 s | **100** | 60–90 |
| 15 s | **55** | 25–50 |
| 10 s | **35** | 18–32 |

通用式（表外时长）：`上限 = round(4.2 × 秒 × 0.79)`；
30 秒口径的绝对偏轻线为 **45 字**。

## 三、超载处置（禁止偷懒）

**被明令禁止的手段**：加字幕速度、整体加速、删台词。

**正确做法**：

1. 先按 `ceil(总字数 / 上限)` 定**最少段数**；
2. 在**镜头边界**上找平衡切分；
3. 镜头粒度不够时，才把某镜台词拆成「前半句 + `角色名画外音继续："后半句"`」跨单元承接；
4. **整句保留优先**。

## 四、切点选择规则

只在「**关系状态发生一次可见变化**」处切：

- 提问落点 / 决定 / 拒绝 / 离场
- 信任建立 / 信息揭示 / 新行动开始

**不在一句完整台词中间切。**

一段切 k 段需 k−1 次插入；**切 3 段以上时，中间段也要各补自己的尾部固定块**（声线块 + `【禁止项】` + `【强制声明】`）。

## 五、已知坑（来自技能实测）

| 坑 | 处置 |
|---|---|
| **声线块挂错段** | 插入的固定块属于**切割点之前那一段**，要列出前一段的出场角色（最易错） |
| **人物站位里的引号污染统计**（曾虚报 3 段超载） | ① 统计时**只取 `^镜头N：` 行内**的引号；② 人物站位里的引用统一改用 `「」` |
| 标题唯一性 | 先改标题再做插入，`replace` 前 `assert count == 1` |
| 声线字典 KeyError | 插入块引用的角色声线必须在字典里，缺一个整体失败 |
| 编码 | 用 `io.open(..., newline='')` 读写避免 LF↔CRLF 污染；Windows 控制台 GBK，脚本 stdout 只用 ASCII |
| 合并稿前言 | 动手前**先整体备份**；合并稿前言（总集数/总段数/总镜头数）需同步更新 |

## 六、校验四条件（缺一不可）

1. 无 `> 上限` 的段；
2. `段数 == 【禁止项】数 == 【强制声明】数 == 人物站位 数`，且段号连续；
3. **镜头总数不变**（重切只移动边界，不增删镜头）；
4. 骨架 grep 校验通过。
