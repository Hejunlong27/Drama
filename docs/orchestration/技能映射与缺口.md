## 四、维护规则

1. **不得再引入「总控台」型技能** —— 三层（前端 / 中端 / 后端）已覆盖全阶段。
2. **规则类内容一律进本仓库**（`docs/orchestration/`），Skill 只放方法论与提示词。
3. 修改任一技能的 `description` 时，**保留末尾的 `【边界·必读】` 段** —— 它是路由准确性的关键。
4. **触发词与说明必须同时互斥**：只补 `【边界·必读】` 而不动触发词表 = 路由歧义未真正消除（这是 2026-10-16 清查出二阶歧义的根因）。
5. 新增同族技能前，先核对本文档第二节的映射表，确认不存在阶段重叠。
