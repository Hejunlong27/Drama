# 验收清单（交付前逐项对照）

> 原则：**每一步都要机器证据，不靠"跑通了"**。没有证据就不要向用户断言"已完成"。

## ① 出片验收

| # | 检查项 | 判据 | 命令 |
|---|---|---|---|
| 1 | 段数齐 | 应有的 shot_id 一个不少 | `drama.py video status <批次>` |
| 2 | 无失败残留 | 失败清单为空 | 同上；有失败先 `--resume` 补跑 |
| 3 | 规格一致 | **1440×832 / 24fps / h264 / aac** | `ffprobe -select_streams v:0 -show_entries stream=width,height,r_frame_rate,codec_name,nb_frames -of csv=p=0 <final.mp4>` |
| 4 | 产物位置 | `<WS>/video-pipeline/output/<批次>/<shot_id>/final.mp4` | — |
| 5 | 台账落盘 | 逐段有 `<WS>/video-pipeline/ledger/runs/<批次>__<段>.json`，且 `attempts[].usage.consumeCoins` 有值 | — |

**注意**：批次的 `summary.json` 要**跑完才写**；跑的过程中想核花费就聚合 `ledger/runs/` 里的 `attempts[].usage`。

## ② 字幕验收（层 2 引擎自带 6 道断言）

| # | 断言 | 判据 |
|---|---|---|
| 1 | 每条字幕时间合法 | 起点 ≥0、终点 ≤总时长、时长 ≥0.4s |
| 2 | 成片帧数 == 母版帧数 | **必须相等**，不等即失败 |
| 3 | **字幕真的画出来了**（像素自检） | 字幕带差异 ≫ 画面其余差异，近白像素显著增加 |
| 4 | 语速合理 | 常规 2.0–8.5 字/秒；>12 告警；> `cps_impossible`（zh 20）判错位并中止 |
| 5 | 声学覆盖 | 列出「有语音却无字幕」的区间 |
| 6 | 段首覆盖修复 | 段首有语音却无字幕 ⇒ 第一条字幕起点前移 |

> **断言 3 是「防假绿」核心**：只看 ffmpeg 退出码 0 不够 —— 字体名写错、字号为 0、路径错，
> ffmpeg 都可能正常退出而画面上什么都没有。

## ③ 字幕**外观**验收（替代人眼，本机无 vision provider）

```powershell
python <skill>\scripts\_qa_subtitle_frame.py ep07 ep08 --all      # 逐条全查
python <skill>\scripts\_qa_subtitle_frame.py ep07 --n 2           # 抽查（最长/最短文本）
```

**方法**：取「母版帧 vs 烧录帧」的差异像素。**单帧差异会被高运动画面污染**（实测有 3 帧包围盒铺满
1440×832，差异像素 8.9万–9.2万，那是画面在动，不是字幕）⇒ 改为**同一字幕内取 5 帧求差异交集**：
字幕在一句之内文本与位置不变，运动像素逐帧变化，交集里几乎只剩字幕。

另外**只在底部 220px 字幕带内度量** —— 否则重编码在画面中部的持续差异会把包围盒撑高
（实测被撑到 y[457,755] 高 298px，误报"偏大"）。

| 检查项 | 配置（1440×832） | 实测通过区间 |
|---|---|---|
| 单行字幕高度 | ≤ 73px | 40–49px |
| 双行字幕高度 | ≤ 140px | 94–105px |
| 底部留白 | 72px | 73–83px |
| 左右边距 | ≥ 60px | 全部在边距内 |
| 漏画/空白 | 0 | **0 条** |

> ⚠️ **这仍不等于「好看」** —— 它证明的是**位置、字号、行数、边距符合配置且没漏画**，
> 审美（配色、字体观感、与画面的搭配）依然需要人眼。

## ④ 成本验收

```powershell
python <skill>\scripts\drama.py cost --checkpoint
```
- 逐项列清：资产 / 视频 / 重跑各花了多少（口径 = 平台 `usage`）
- 说明「余额只用于判断够不够跑，不做消耗归因」
- 给出 `docs\成本台账_<剧名>.xlsx` 路径
