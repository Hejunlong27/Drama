# 成本口径与结账（实测，不要再用公式外推）

## 一、两条铁律

1. **消耗只认平台按任务返回的 `usage`**（`consumeCoins` / `consumeMoney` / `thirdPartyConsumeMoney`），逐条累加。
2. **绝不用余额差值倒推消耗**（用户 2026-09-19 明确纠正）—— 余额变动混入充值、订阅续费、其他产品与其他使用者。
   **余额只用于判断「够不够跑」，不做归因。**

有了 RH币↔USD 换算才能把两个池并成一个数字记账。

## 四、失败率（必须预留）

**实测 4/44 = 9.1%**（ep03 2/13、ep04 1/13、ep05+06 1/18）—— 全部报「工作流运行失败」、
**全部未计费、全部重跑即过** ⇒ 平台侧一次性失败。

> 反例：ep07–10 一整批 **20/20 成功、0 失败**（3,074 RH币 / 53 分钟）。
> **运气好不代表下次也好** —— 仍按 ~10% 预留重跑的时间与钱。

**重跑命令**（不重复扣费）：
```powershell
python <skill>\scripts\drama.py video run --yes --resume <批次> --only <失败段,失败段>
```
**不要改提示词或配置** —— 那是平台侧 transient。

## 五、结账（每个任务收尾都要跑）

```powershell
python <skill>\scripts\drama.py cost --checkpoint   # ★ 收工结账：记基线 + 出 Excel + 出 markdown
python <skill>\scripts\drama.py cost                # 只看台账、刷新 Excel（不重置基线）
python <skill>\scripts\drama.py cost --balance      # 附带只读余额（仅判断够不够跑）
```

产物：
- **`<WS>\docs\成本台账_<剧名>.xlsx`** ← 主交付物（7 个工作表）
- `<WS>\docs\成本台账.md`（纯文本版）
- `<WS>\docs\cost-checkpoint.json`（结账基线）

Excel **只清空并重写「表头下面那几行数据」** ⇒ 你自己加的批注、新建的工作表、
数据区之外的备注行都保留。汇总格是 `SUMIF` 公式，改明细会自动重算。

## 六、token 归属只能「近似」

DSH 账本只有「按天/按会话」粒度，**没有逐批次时间戳** ⇒ 无法把某段 token 精确归到某个批次。
做法是**每做完一个任务就打一次 `--checkpoint`**，按「结账区间增量」归属：
区间内恰好 1 个新批次 ⇒ 归该批次；多个新批次但同属一大类 ⇒ 归该大类；跨大类 ⇒ 进「未归属」。

> ⚠️ **无论如何都是近似**：区间内若同时在改文档/排查，那部分 token 也会算进来。
> **历史任务无法回溯拆分。** token 走包月订阅时 `apiCost` 为 0 ⇒ **名义计费 ≠ 实际扣费**，两个数都报、不混为一谈。
