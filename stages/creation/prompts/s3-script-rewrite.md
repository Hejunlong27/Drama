# 第四部分 · 剧本改写（LLM 提示词模板）

> 用途：指导会话内 LLM 按 `03-剧本/blueprint.json`（④的结构规划，唯一指令来源）
> 与 `script-brief.md`，把源剧本改写成 **N 集（默认 40 集 × 70 秒）** 的 FFS 正文。
>
> `script_rewrite.py` 已完成确定性部分：集数规划（每集的**开场钩子/核心冲突/反转/集尾钩子**）、
> FFS 骨架、结构与格式自检。LLM 负责把每集写成可拍的正文。
>
> ★ **强度依据**：`docs/creation/剧本强度工程.md`（根本原因 / 改写策略 / 质控标准）。
> 题材公式模式下，每集还带公式化要求（打脸/等级/见证者/压放/里程碑/金句）。

## 任务

> **四、剧本改写**：把源剧本改写成**完整 N 集规划**（默认 40 集，每集 70 秒），
> 每集须包含**开场钩子 + 核心冲突 + 一次反转 + 集尾钩子**；整体**节奏紧凑、钩子密集、爽点高频**。
>
> **要解决的问题**：此前两个试验项目「剧本过于简单、缺乏爽点引爆感」。
> 根因是**结构缺陷**（压迫不透、打脸无阶梯、无见证者、台词无攻击性、前 3 集先铺垫），不是内容量不够。

## 前置

1. 源剧本放到 `03-剧本/source-script.md`；
   **非目标语种先转译**（见 `prompts/s0b-script-translate.md`），转译质检通过后再进本环节。
2. 定路线（二选一）：
   - **常规**：③选题定位已就位 → `script_rewrite.py plan`（默认 40 集）。
   - **题材公式**：命中关键词（如「女主逆袭」）→ `genre_formula.py apply --genre female-comeback`
     → `script_rewrite.py plan --genre female-comeback`（**跳过选题**）。
3. 单集骨架：`script_rewrite.py build --ep N --emit` → `03-剧本/ep_XX.md`。

## 改写方式（源剧本 → 新规划）

1. **保留**源剧本的核心人设、设定魅力与最「颠」的爽点机制（这是它的价值所在）。
2. **重排**为 N 集结构（见 blueprint 的 `episodes`），**每集必须同时具备**：
   - **开场钩子**（`cold_open`）—— 前 3–5 秒出「异常/冲突/悬念」；EP1 为**黄金 3 秒**
   - **核心冲突**（`core_conflict`）
   - **一次反转**（`reversal`）—— 必须改变力量对比或信息格局
   - **集尾钩子**（`hook`，7 型之一：身份悬念/危机逼近/关系反转/秘密揭露/选择困境/意外登场/代价预告）
3. **加密**钩子与爆点：按 `boom_cadence` 植入中型爆点（每 4 集）与大型爆点（每 10 集）。
4. **节奏**：单镜 4–15 秒、单集 5–12 镜、**单集总时长 70–95 秒（目标 70 秒）**；开场 1–2 镜短促抓人，集尾短收。

## ★ 爽感强化（本环节的硬要求）

### 一、前 3 集爆款钩子公式（骨架不可改）

| 集 | 开场 | 集尾钩子 |
|---|---|---|
| EP1 | **黄金 3 秒**：全剧最高冲突前置（当众被打脸瞬间 / 最惨时刻 / 身份反差）；**禁交代式开场** | 底牌露一角：观众知道「她不是软柿子」，但不解释是什么 |
| EP2 | 压力加码（第二件坏事）+ 明确对手是谁 | 立誓：说出要拿回什么、向谁拿 |
| EP3 | 第一次反击的起点 | 首次小打脸落点 + 暴露下一级对手 |

EP1-3 钩子类型**互不相同**，且不得与前 2 集连续重复。

### 二、打脸五拍（缺一拍即判定「打脸未完成」）

**挑衅 → 压制 → 反转 → 见证 → 追加一击**

- **第 2 拍「压制」最常被漏**：必须让观众**短暂相信她这次要输** —— 没有「以为她要输」，就没有「她赢了」的爽。
- **第 4 拍「见证」不可省**：围观者反应（震惊/失语/倒戈/道歉）是**爽感放大器**；
  羞辱与反击尽量在**同一场景、同一批人**面前回收。
- 反转的底牌**必须前文埋过**；临时掏出的底牌 = 金手指，爽感归零。

### 三、对手阶梯与循环铁律

- **四级阶梯**：L1 势利小人物 → L2 中层对手 → L3 实权者 → L4 隐藏大 boss；打倒一级**立刻暴露下一级**。
- **每轮循环必须「拿走一样 + 暴露一样」**：拿走可量化所得（职位/合同/股份/道歉），暴露更大的对手或隐情。

### 四、压放呼吸

- 每 3 集内至少 1 次「压」+ 1 次「放」；**禁止连续 3 集同向**。
- 触底段（前 3 集）**全部为压** —— 释放感越晚越强；终局段以「扬/燃」收尾。

### 五、台词可以更大胆

- **允许**：直接揭短（当众点名事实）｜明确最后通牒（「今天之内搬走」）｜冷调反讽｜亲属关系里的狠话（断亲、逐出、罢免）。
- **禁止**：空话式威胁（「我一定会让你付出代价」）｜解释型台词（把观众已看到的再说一遍）｜工具人台词（「我发现了一个秘密」却不说是什么）。
- **金句**：≤12 字 + 含具体事物（人名/物件/数字/关系）；放在五拍的**第 5 拍**；**每集 ≥1 句**可摘录、可传播的句子。
- 公式模式下每集 blueprint 已给 `quote`（金句方向），照它落笔。

### 六、题材公式字段（公式模式下每集附带）

`punch`（打脸对象+方式，含五拍）/ `punch_level`（1–4）/ `witness`（是否有见证者）/
`stake`（压/放/悬）/ `milestone`（事业线里程碑）/ `quote`（金句方向）。
**正文必须覆盖这六个字段**，写完后跑公式 QC 复核。

## 正文格式（FFS，严格）

按 `docs/creation/ffs-spec.md`：

- **HEADER 六字段**：`# TITLE` / `# EP` / `# PLATFORM` / `# STYLE LOCK` / `# CHAR` / `# SCENE`；
  `STYLE LOCK` 逐字复制 blueprint 的 `style_lock`。
- **镜头块 8 字段**（顺序固定）：`[SC-xx]` + SHOT / LOCATION / TIME / CHAR / ACTION / DIALOG / VO / SFX（可选 DUR）。
- **禁止自定义字段**（MOOD/CAMERA/EMOTION/MUSIC/LIGHT 触发 E004）；情绪写进 ACTION 的**具体动作与表情**。
- `ACTION` 必须出现角色代号或名字；镜头块内只引用 HEADER 代号。

### 台词与旁白

- 每句台词先归类功能（推进/引爆/揭示/悬念/关系），**无功能的台词不写**。
- 按**目标语种**写口语，禁翻译腔；按该语种语速折算匹配镜头时长
  （中文 4.2 字/秒；西语约 3.5–4 词/秒；详见 `references/translation-languages.json`）。
- `VO` 带来源前缀（`NARRATOR:` / `角色名 (V.O.):`），每集 ≤5 处。
- 双语交付：目标语正文 + 中文译稿。

## 差异化红线（违反即失败）

见 `script-brief.md` 的「四、差异化红线」，重点：不复刻源剧本/对标剧的台词与镜序；不与他人共用同一冲突结构；
反套路必须指明反的**具体**套路；本土化要可代入；每集四件套（开场钩子+冲突+反转+集尾钩子）缺一不可。
