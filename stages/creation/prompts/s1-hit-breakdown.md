# 第二部分 · 爆款拆解（LLM 提示词模板）

> 用途：脚本 `hit_breakdown.py` 已用**确定性算法**完成拆解（题材分布 / 剧情套路 / 爆点元素 / 榜单洞察 /
> 内容偏好 / 差异化趋势）。本模板用于会话内 LLM **复核与解读**，把它写成可读的「第二部分」交付文本。

## 任务

> **二、爆款拆解**：基于榜单数据，拆解**热门题材类型、常见剧情套路与核心爆点元素**，
> 总结**西语市场的内容偏好与差异化趋势**。

## 机读产物（脚本已产出，勿改结构）

`creation/01-breakdown/breakdown.json`：

- `genre_distribution[]`：题材类型分布（数量/占比/例）。
- `tropes[]`：剧情套路库（命中数/占比/例）—— 如身份反转 / 血统觉醒 / 复仇打脸 / 契约关系。
- `boom_elements[]`：爆点元素频次 —— 如身份揭穿 / 当众打脸 / 觉醒变强 / 死亡反转。
- `ranking_insights`：按平台、按题材的榜单条目聚合。
- `content_preferences[]`：按市场（西语置顶）的题材偏好与主套路。
- `differentiation_trends[]`：长尾/未饱和/趋势提及但未成对标的**蓝海切口候选**。

## LLM 复核任务

输出「第二部分」正文，必须包含：

1. **热门题材类型**：给 Top N（引 `genre_distribution` 的数量与占比）。
2. **常见剧情套路**：给 Top N（引 `tropes`），并写**一句话说明每个套路的爽点机制**。
3. **核心爆点元素**：给 Top N（引 `boom_elements`），说明它在哪一拍引爆。
4. **西语市场内容偏好**：明确「西语观众吃哪几套」（引 `content_preferences` 中 `is_spanish=true` 的条目），
   包含本土化代入点（家庭关系 / 阶层落差 / 都市浪漫 / 足球等）。
5. **差异化趋势**：从 `differentiation_trends` 里挑 2–3 条，写成**可执行的差异化切口建议**
   （说明「为什么现在做它、风险是什么」）。
6. **结论**：一句话给出「本批要做的话，顺势做哪个套路 + 在哪切差异化」。

## 硬约束

- 一切结论必须**可回指**到 breakdown.json 的条目（哪条套路、哪个市场、哪个数字），禁止凭空断言。
- 不复述剧情，不下「票房预测」式确定性承诺。
- 蓝海判断要说明依据（长尾/未饱和），不要仅凭感觉说「新」。
